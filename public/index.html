Get started

  1. Open the Library tab and drop in some MP3s — see MUSIC-LIBRARY.md for free, venue-safe tracks.
  2. Create a Lunch and a Dinner playlist, add tracks with +.
  3. Set them on the Schedule tab — the music switches automatically through the day.
